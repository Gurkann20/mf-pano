Personel girişini kur

Bu sayfa, personelin yönetim paneline kullanıcı adı ve şifreyle girebilmesini sağlar. GitHub erişim anahtarı bu kullanıcı adı ve şifreyle şifrelenip depoya yonetim/giris.json olarak kaydedilir. Şifre hiçbir yere kaydedilmez; unutulursa bu sayfadan yenisi kurulur.

1. GitHub erişim anahtarı

  1. GitHub → Fine-grained token oluştur sayfasını açın.
  2. Repository access: yalnızca bu sitenin deposunu seçin.
  3. Permissions → Contents: Read and write. Başka izin vermeyin.
  4. Oluşan github_pat_… anahtarını aşağıya yapıştırın.
